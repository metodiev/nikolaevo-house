## Основна логика на разположението

| Помещение | Ключово решение |
|---|---|
| **Кухня** | Г-образен плот 600 mm: мивка под прозореца, котлони на западния плот, хладилник в североизточния ъгъл |
| **Трапезария** | Маса 1400 × 900 с 6 стола — между кухнята и хола, до източния прозорец |
| **Хол** | Диван 2200 mm с гръб на изток, срещу телевизора на западната преграда |
| **Спалня 1** | Легло 1600 × 2000 с табла на вътрешната преграда, гардероб 1600 mm |
| **Спалня 2** | Легло 1600 × 2000 с табла на западната стена, гардероб 1200 mm |
| **Баня** | Душ 1200 × 900, WC, мивка с шкаф 1000 mm |
| **Мокро** | Пералня, сушилня, плот с мивка, бойлер, вентилация |
| **Антре** | Гардероб 400 mm, пейка, електрическо табло |

Пълен списък с размери: [01-obzavezhdane.md](./01-obzavezhdane.md).

## Важни ограничения

1. **Гардеробите са с плъзгащи врати** — при 550 mm дълбочина крилата не могат да
   се отварят навън без да блокират прохода.
2. **Леглата са с табла на вътрешна стена** — не под прозорец.
3. **Пред плъзгащата врата на юг** се оставя свободна зона поне 1200 mm.
4. **Кухнята е на север** — плотът е под прозореца, но осветлението над плота
   трябва да е изкуствено и достатъчно.
5. Размерите на мебелите в схемите са типични за българския пазар — при поръчка
   се проверяват спрямо избрания модел.

## Как се генерират

```bash
python furniture/generate_furniture.py       # SVG в plans/
python tools/export_png.py furniture         # PNG в images/
```

Скриптът държи геометрията на сградата и обзавеждането на едно място — при
промяна на план се редактира само той.
