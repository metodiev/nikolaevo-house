# Материали

Спецификация на основните материали по концепцията.

> Количествата **не са изчислени** — те са предмет на количествена сметка по
> работен проект. Тук е само обхватът, за да се сравняват оферти по еднакъв
> списък.

## 1. Конструкция

| Материал | Предназначение | Количество | Статус |
|---|---|---|---|
| ICF блокове (EPS, с бетонно ядро) | външни стени | по сметка (~110–120 m² стена) | ❓ избор на система |
| Бетон за ядрото | ICF стени | по сметка | ❓ клас по проект |
| Армировка (вертикална + хоризонтална) | ICF стени | по сметка | ❓ по проект |
| Бетон за фундамент и плоча | ивични фундаменти, подова плоча | по сметка | ❓ по проект |
| XPS изолация 100–150 mm | под плочата + периметър | по сметка | ❓ |
| Хидроизолация (битумна мембрана) | под плочата, фундамент | по сметка | ❓ |
| Дренаж (тръби + геотекстил + чакъл) | около фундамента | по сметка | ❓ според терена |

## 2. Покрив

| Материал | Предназначение | Количество | Статус |
|---|---|---|---|
| Дървени ферми / греди | носеща конструкция, пролет 8,20 m | по сметка | ❓ по проект |
| OSB / летви | основа | по сметка | ❓ |
| Покритие (керемиди / метал / друго) | двускатен покрив | по сметка | ⬜ избор |
| Топлоизолация (минерална вата / PIR) | таван/покрив | по сметка | ❓ по енергиен проект |
| Улуци и водосточни тръби | отвеждане | по сметка | ❓ |

## 3. Дограма

| Материал | Предназначение | Количество | Статус |
|---|---|---|---|
| Прозорци (PVC или алуминий с термомост) | 6 бр. + 1 опция | по спецификация | ❓ |
| Плъзгаща врата 2,80 m | хол → тераса | 1 бр. | ❓ |
| Входна врата | изток | 1 бр. | ❓ |
| Вътрешни врати 0,90 m | 5 бр. | 5 бр. | ❓ |
| Външно засенчване (надвес / пергола / ролетки) | юг, изток | по сметка | ⬜ решение |

Подробно: [спецификация на дограмата](../architecture/03-openings.md)

## 6. Какво липсва

- Количествени сметки по позиции
- Марки и модели на конкретни продукти
- Оферти от доставчици

При поръчка се сравняват **едни и същи позиции** — иначе офертите не са сравними.
