# Проучвания

Инженерни и геоложки проучвания.

## Какво трябва да има

| Документ | Защо е нужен | Статус |
|---|---|---|
| Инженерно-геоложки доклад (сондажи) | носеща способност, ниво на подпочвени води, дълбочина на фундиране | ❓ задължителен |
| Геодезично заснемане | коти, граници, денивелация | ❓ |
| Доклад за агресивност на почвата | защита на бетона | ❓ при нужда |
| Енергийно проучване (по избор) | соларен потенциал, засенчване | ⬜ |

## Забележка

Без геоложки доклад **не може да се оразмери фундаментът** и не може да се даде
реална цена. Това е първата стъпка преди конструктивния проект.

**Все още няма качени документи.**
