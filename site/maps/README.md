# Карти

Карти, извадки и ситуационни материали.

## Какво трябва да има

- [ ] Извадка от ПУП (подробен устройствен план) — зона, отстояния, височина
- [ ] Ситуационен план на района
- [ ] Сателитна/ортoфото снимка с очертан парцел
- [ ] Информация за съседната застройка

## Защо е важно

ПУП определя **отстоянията, максималната височина, плътността и вида на
покрива**. Това са ограниченията, които най-често променят концепцията.

**Все още няма качени материали.**
