# Кадастър

Тук се съхранява кадастралната информация за парцела.

## Какво трябва да има

- [ ] Кадастрална скица (актуална извадка)
- [ ] Скица на имота с координати на граничните точки
- [ ] Документ за собственост
- [ ] Удостоверение за данъчна оценка (при нужда)
- [ ] Информация за съседните имоти и техните граници

## Защо е важно

От кадастъра се вземат **точните размери, граници и площ на парцела**. Без тях не
може да се провери дали сградата 12,00 × 8,20 m се побира с отстоянията по ПУП.

**Все още няма качени документи.**
