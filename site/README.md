# Парцел

Информация за мястото: кадастър, карти, измервания, проучвания.

## Папки

| Папка | Съдържание |
|---|---|
| [cadastral](./cadastral) | Кадастрална скица, имотни граници |
| [maps](./maps) | Карти, извадки, ситуация |
| [measurements](./measurements) | Измервания на терена |
| [surveys](./surveys) | Геодезия, геология, сондажи |

## Известно

- Достъп до парцела: **от изток**.

## Неизвестно

- Точни размери и граници, отстояния по ПУП, денивелация, геология и подпочвени
  води — вж. [отворените въпроси](../documentation/02-open-questions.md).
