# Електроинсталация

Предстои проектиране.

## Връзка с концепцията

- ICF стените **не се къртят** — трасетата се планират предварително в преградите,
  замазката и окачения таван.
- Контакти и ключове на външните стени — с предварително заложени тръби в кофража.
- Табло — в близост до входа (антре).
- Външни тела на климатизация — по северната фасада.
