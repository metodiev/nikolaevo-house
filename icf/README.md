(кофражните блокове) за къщата.

> Основа: **12,00 × 8,20 m, 98,4 m² застроена площ**, вход от изток.

## Кратко за обхвата

| Параметър | Стойност |
|---|---|
| Сграда | едноетажна, самостоятелна, правоъгълна |
| Габарит по външни стени | 12,00 × 8,20 m |
| Височина на стената до стреха | 3,00 m |
| Външни ICF стени | 4 бр., дебелина **350 mm** (работно допускане) |
| Отвори | **8 бр. + 1 опция** |
| Брутна площ на стените (по ос) | 117,00 m² |
| Нетна площ ICF стена | ≈ 99,7 m² |
| Вътрешни прегради | **не са ICF** — газобетон / гипсокартон, доставят се отделно |
| Фронтони (габъли) | **не са ICF** — лека конструкция |

---

## Важно преди изпращане

1. **Дебелината 350 mm е работно допускане.** Всяка ICF система има различна
   дебелина (250–400 mm). Ако избереш система с друга дебелина, чистата площ на
   стаите се променя с 1–3 m² — това трябва да се съгласува с проектанта
   **преди** архитектурния проект.
2. **Това е скица за оферта, не работен проект.** Фирмата трябва да разбере, че
   количествата са ориентировъчни и се уточняват по работен проект.
3. **Поискай оферта по позиции**, не обща сума — иначе не може да се сравни с
   друга оферта. Виж [05-sravnenie.md](./05-sravnenie.md).
4. **Не приемай устни уточнения.** Всичко, което се разбере по телефона, се
   записва в офертата.

## Файлове в папката

```
icf/
├── README.md                     ← този файл
├── 01-zadanie.md                 задание и обхват
├── 02-steni-i-otvori.md          таблица на стените и отворите
├── 03-kolichestva.md             количества
├── 04-vaprosi.md                 въпросник към доставчика
├── 05-sravnenie.md               сравнение на оферти
├── generate_icf_drawings.py      генератор на скиците (единичен източник на данни)
├── export_png.py                 SVG → PNG чрез headless Chrome
├── plans/                        SVG скици, 1:100 и 1:40
└── images/                       PNG версии, 2400 px
```

Ако се промени размер на стена или отвор: редактира се **само** секция 2 в
[generate_icf_drawings.py](./generate_icf_drawings.py), стартира се скриптът и
след него `export_png.py`. Всички чертежи и количества се обновяват заедно.
