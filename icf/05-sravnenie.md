# Сравнение на оферти

Работен документ за теб — не се изпраща на доставчиците.

> Попълва се след като получиш офертите. Целта е да се сравни **един и същ
> обхват**, а не обща сума.

## 4. Червени флагове

Отбележи, ако е налично:

| Сигнал | A | B | C |
|---|---|---|---|
| Дава само обща сума без разбивка | | | |
| Не посочва дебелина и модул | | | |
| Не дава сертификати | | | |
| Няма референтни обекти | | | |
| Оферира вътрешни прегради като ICF (неправилно) | | | |
| Оферира фронтони без да е поискано | | | |
| Цена значително под останалите | | | |
| Отказва да отговори на въпросника | | | |
| Иска голям аванс без гаранция | | | |
| Няма писмена гаранция | | | |

Цена значително под останалите обикновено означава **различен обхват**, а не
по-добра сделка.

## 5. Въпроси преди подписване

- [ ] Всички допускания са записани в офертата (дебелина, модул, клас бетон)
- [ ] Ясно е кой носи отговорност при дефектен блок
- [ ] Ясно е кой носи отговорност при грешен монтаж
- [ ] Срокът е обвързан с готовността на фундамента
- [ ] Условията за плащане са разумни
- [ ] Гаранцията е писмена
- [ ] Количествата ще се актуализират по работен проект
- [ ] Проектантът е запознат с избраната система
