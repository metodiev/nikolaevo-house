# Отопление и вентилация

Предстои проектиране.

## Връзка с концепцията

- **Вентилация с рекуперация е практически задължителна** — ICF къщата е херметична.
  Агрегатът се позиционира в мокрото помещение.
- Отопление: подово в замазката е най-съвместимо с ICF (ниска температура).
- Баня и мокро помещение: механично изсмукване, независимо от прозорците.
- Северната фасада е подходяща за външни тела на климатизация.
- Източник на топлина (термопомпа / газ / пелети) — **за решение**.
