# 3D модел на къщата

Обемен модел на едноетажната ICF къща — за оглед отвън и отвътре, със и без
обзавеждане. Геометрията се строи от **същите размери**, използвани в 2D
чертежите, така че не може да се разминава с тях.

> Това е **концептуален обемен модел**, не работен проект. Мебелите са с
> примерни размери и форми; покривът е опростен; няма конструктивни детайли,
> инсталации и точно осветление.

---

## 1. Какво има в папката

| Файл | Какво е |
|---|---|
| [model.html](./model.html) | **Интерактивен 3D изглед** — отваря се с двоен клик в браузър |
| `model-data.js` | Геометрията, която `model.html` зарежда (генерира се) |
| `model-data.json` | Същата геометрия като JSON — за други инструменти |
| `house-full.obj` + `.mtl` | 3D модел **с обзавеждане** — за Blender, SketchUp, Revit и др. |
| `house-shell.obj` + `.mtl` | 3D модел **само конструкция** — без обзавеждане |
| [generate_3d.py](./generate_3d.py) | Скриптът, който строи всичко и рендира картинките |
| `images/` | Рендерите (виж по-долу) |

Всичко се пресъздава с една команда:

```
python generate_3d.py
```

---

## 2. Интерактивният изглед

Отвори [model.html](./model.html) с двоен клик — работи без интернет и без
инсталация (данните са в `model-data.js`).

- **Влачене с мишката** — завъртане
- **Колело** — увеличение
- **Десен бутон** — преместване
- Отметки: обзавеждане / покрив / таван / стени и дограма / основа и подове
- Бутони за готови гледни точки: външна югоизток и североизток, план отгоре,
  вътре в хол, кухня и спалня
> При избор на вътрешна гледна точка покривът се скрива автоматично, а таванът
> остава — иначе се вижда само небето.

## 5. Ограничения

- **Покривът е опростен** — без ферми, улуци, снегозадържачи.
- **Обзавеждането е блоково** — правоъгълници с правилните размери и позиции,
  но без форми и детайли. За покупка се ползва [furniture/01-obzavezhdane.md](../furniture/01-obzavezhdane.md).
- **Няма инсталации** — тръби, кабели и въздуховоди не са моделирани.
- **Няма терен** — земята е равна равнина.
- **Осветлението е условно** — два посоки + околна светлина, не е фотореализъм.
- Файловете `.obj` са с метрични единици. Ако нормалите изглеждат обърнати в
  дадена програма, пусни „Recalculate Outside" (Blender: Shift+N).
