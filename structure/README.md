## Накратко

- **Външни стени** — носещи ICF стени с бетонно ядро, затворен правоъгълен контур.
- **Вътрешни стени** — неносещи прегради (газобетон или гипсокартон).
- **Покрив** — двускатен, дървена конструкция, стъпва само на външните стени.
- **Под** — плоча върху земя с непрекъсната топлоизолация под нея.
