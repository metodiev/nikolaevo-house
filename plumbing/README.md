# ВиК

Предстои проектиране.

## Връзка с концепцията

- Всички мокри функции са **групирани по северната стена**: баня, мокро помещение,
  кухня — къси трасета и обща водопроводна стена.
- Мивката в кухнята е плътно до преградата към мокрото помещение.
- Бойлер / термопомпа за вода — в мокрото помещение.
- Препоръчва се подово отопление в замазката (ниска температура на топлоносителя).
- Захранване и канализация — **неизвестни**, за проверка в ЕРП/ВиК.
