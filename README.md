# Nikolaevo House

Проект за къща

##  Project

Целта на този repository е да съхранява и организира цялата информация,
свързана с проектирането, изграждането и развитието на къщата.

Проектът включва:

- Архитектура
- Конструкция
- Електроинсталация
- ВиК
- Отопление и вентилация
- Двор и ландшафт
- Материали
- Бюджет
- Документация
- Снимки и измервания
