# CAD — генератор на план

Python скрипт, който генерира концептуален план на едноетажна ICF къща като DXF
и го експортира като PNG/SVG.

## Вариант

Това е **отделен компактен вариант** на къщата — не същият като основната
концепция в [../01-concept-plan.md](../01-concept-plan.md):

| Параметър | Този вариант | Основна концепция |
|---|---|---|
| Габарит | 12,00 × 7,60 m | 12,00 × 8,20 m |
| Застроена площ | 91,2 m² | 98,4 m² |
| Външни стени | 0,25 m | 0,35 m |
| Чиста площ | 78,98 m² | 80,3 m² |
| Хол + кухня | 31,95 m² | 30,8 m² |
| Антре | няма (вход директно в дневната) | 4,0 m² |

## Файлове

| Файл | Съдържание |
|---|---|
| `generate_plan.py` | Скриптът |
| `house.dxf` | Генериран чертеж (R2010, единици: метри) |
| `house.png` | Растерно изображение, 200 dpi |
| `house.svg` | Векторно изображение |

## Стартиране

```bash
pip install -r ../../requirements.txt
python generate_plan.py               # DXF + PNG + SVG
python generate_plan.py --no-image    # само DXF
python generate_plan.py --outdir out  # друга изходна папка
```

Скриптът отпечатва и контролна сметка на площите; ако хол + кухня падне под
30 m² или застроената площ излезе извън 75–99 m², спира с грешка.

## Слоеве

| Слой | Съдържание |
|---|---|
| `WALLS` | стени (запълнени с плътна hatch) |
| `DOORS` | врати — крило + дъга на отваряне |
| `WINDOWS` | прозорци и плъзгаща врата |
| `ROOMS` | затворени контури на помещенията + надписи с площ |
| `DIMENSIONS` | размерни вериги, рамка, север |

Контурите в `ROOMS` са затворени полилинии — площта може да се измери директно
в CAD с `AREA` / `MASSPROP`.

## Структура на кода

| Част | Съдържание |
|---|---|
| 1. Константи | габарити, дебелини, ширини на отвори, текстове |
| 2. Изчислена геометрия | координати на осите, произлизащи от константите |
| 3. Модели | `Room`, `Wall` (dataclasses) + списъци `ROOMS`, `WALLS`, `DOORS`, `WINDOWS` |
| 4. Помощни функции | слоеве, текстов стил, размерен стил, надписи |
| 5. Чертане | `draw_room()`, `draw_wall()`, `draw_window()`, `draw_door()`, `draw_dimensions()` |
| 6. Сглобяване | `build_house()`, `report()` |
| 7. Експорт | `export_images()` |
| 8. `main()` | CLI |

### `draw_room()`

Основната функция за чертане на стая по координати:

```python
area = draw_room(msp, x1, y1, x2, y2, "СПАЛНЯ 1")
# → чертае затворен контур, надпис с размери и площ, връща площта в m²
```

## Забележки

- Чертежът е концептуален — не е строителен проект.
- Шрифтът е Liberation Sans (TrueType), за да се визуализират коректно
  кирилицата и символите `×`, `·`, `²`. При липса на шрифта в CAD се замества
  автоматично.
- Размерите са в **метри** (не в милиметри), както е зададено в скрипта.
