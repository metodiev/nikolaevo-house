# CAD — генератор на план (DXF)

Python скрипт, който генерира концептуалния план на къщата като DXF и го
експортира като PNG/SVG.

Чертае **същата къща** като всички останали чертежи в проекта:

| Параметър | Стойност |
|---|---|
| Габарит | 12,00 × 8,20 m |
| Застроена площ | 98,40 m² |
| Вътрешна площ в светли отвори | 84,75 m² |
| Чиста използваема площ | 80,28 m² |
| Външни ICF стени | 0,35 m |
| Вътрешни прегради | 0,15 m (0,12 m при антрето) |
| Височина до стреха | 3,00 m |

При стартиране скриптът **сам проверява** дали изчислените площи съвпадат с
тези стойности и отпечатва `✓ Площите съвпадат с останалите чертежи в проекта.`
Ако някой размер се промени и не е синхронизиран — виждаш `ГРЕШКА`.

## Файлове

| Файл | Съдържание |
|---|---|
| `generate_plan.py` | Скриптът |
| `house.dxf` | Генериран чертеж (R2010, единици: метри) |
| `house.png` | Растерно изображение, 200 dpi |
| `house.svg` | Векторно изображение |

## Стартиране

```bash
pip install -r ../../requirements.txt
python generate_plan.py               # DXF + PNG + SVG
python generate_plan.py --no-image    # само DXF
python generate_plan.py --outdir out  # друга изходна папка
```

## Слоеве

| Слой | Съдържание |
|---|---|
| `WALLS` | стени и прегради (запълнени с плътна hatch) |
| `DOORS` | врати — крило + дъга на отваряне |
| `WINDOWS` | прозорци и плъзгаща врата |
| `ROOMS` | затворени контури на помещенията + надписи с площ |
| `DIMENSIONS` | размерни вериги, рамка, север |

Контурите в `ROOMS` са затворени полилинии — площта може да се измери директно
в CAD с `AREA` / `MASSPROP`.

## Структура на кода

| Част | Съдържание |
|---|---|
| 1. Константи | габарити, дебелини, ширини на отвори, очаквани площи |
| 2. Модели | `Room`, `Wall` (dataclasses) + `ROOMS`, `WALLS`, `DOORS`, `WINDOWS` |
| 3. Помощни функции | слоеве, текстов стил, размерен стил, надписи |
| 4. `draw_room()` | чертане на стая по координати |
| 5. Чертане | `draw_wall()`, `draw_window()`, `draw_door()`, `draw_dimensions()` |
| 6. Сглобяване | `build_house()`, `report()` |
| 7. Експорт | `export_images()` |
| 8. `main()` | CLI |

### `draw_room()`

Основната функция за чертане на стая по координати:

```python
area = draw_room(msp, x1, y1, x2, y2, "СПАЛНЯ 1")
# → затворен контур, надпис с размери и площ; връща площта в m²
```

Допълнителни параметри:

| Параметър | Значение |
|---|---|
| `show_size` | дали да се изпишат размерите и площта |
| `label` | дали да се изпише името (при тясно помещение се изписва отделно) |

## Забележки

- Чертежът е концептуален — не е строителен проект.
- Шрифтът е Liberation Sans (TrueType), за да се визуализират коректно
  кирилицата и символите `×`, `·`, `²`. При липса на шрифта в CAD се замества
  автоматично.
- Размерите са в **метри** (не в милиметри).
